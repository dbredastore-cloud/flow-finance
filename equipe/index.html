Desligar o cadastro público

Hoje qualquer pessoa pode criar uma conta pela API do Supabase. Ela não vê nenhum dado (só quem está na lista acima vê), mas o ideal é fechar a porta. Isso é feito no painel do Supabase, não aqui:

  1. Abra Authentication → Sign In / Providers do projeto.
  2. Em User Signups, desligue Allow new users to sign up e clique em Save changes.
  3. Confira em Authentication → Users se não há contas estranhas; o que sobrar sem acesso aparece em "Contas sem acesso" aqui.

Esta tela continua criando contas normalmente com o cadastro público desligado, e quem já tem conta continua entrando.
